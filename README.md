# 스페인어 플래시카드 (스페인 본토 우선)

아내를 위한 중급 이상 스페인어 학습 앱입니다.

- **앞면**: 한국어 문장/뜻
- **뒷면**: 스페인어 세 가지 변형
  - **구어체 (스페인 본토)** — vosotros, ordenador, vale 등 본토 표현 우선
  - **문어체** — 격식·문어에 가까운 표현
  - **중남미 구어체** — 비교 학습용

공개 페이지: https://blackupjacob.github.io/spanish-flashcards/

## 사용 방법

1. **주제**를 고릅니다. (일상, 직장, 여행, 음식, 감정, 문화, 시사·뉴스, 관용구, 격식 상황 — 여러 개 선택 가능)
2. **난이도**를 고릅니다. (`전체` / `아주쉬움` / `쉬움` / `어려움` / `아주어려움`)  
   ※ «아주쉬움»도 관광 기초가 아니라 **중급 초반** 수준입니다.
3. **학습 모드**
   - **기본 학습**: 한국어 → 스페인어(본토 구어 기준). 뒷면에 세 변형 모두 표시.
   - **혼합 재학습**: 앞면은 여전히 한국어. 카드마다 **구어체 / 문어체 / 중남미** 중 하나를 목표로 지정합니다. (한 바퀴 끝난 뒤 요약 화면에서 바로 시작 가능)
4. **내 CSV 덱** (선택): 직접 만든 문장 CSV를 올려 공부할 수 있습니다.
5. 카드를 **탭**해 뒤집고 **맞음 / 틀림**을 고릅니다. 틀린 카드는 큐에 다시 들어갑니다.

진행 상태와 업로드한 CSV는 브라우저 `localStorage`에 저장됩니다.

## CSV로 카드 추가

1. [sample-cards.csv](sample-cards.csv)를 받아 열을 맞춥니다. (Excel은 **UTF-8 CSV**로 저장)
2. 앱에서 파일을 선택합니다.
3. 덱 출처를 고릅니다.
   - **기본 덱** — 앱에 들어 있는 카드만
   - **CSV만** — 업로드한 카드만
   - **합치기** — 둘 다

### 열 (헤더)

| 열 이름 | 설명 |
|---------|------|
| `front_ko` | 앞면 한국어 문장 (필수) |
| `colloquial_es` | 스페인 본토 구어체 (필수) |
| `formal_es` | 문어체/격식 (필수) |
| `latam_colloquial_es` | 중남미 구어체 (필수) |
| `difficulty` | `아주쉬움` \| `쉬움` \| `어려움` \| `아주어려움` |
| `topics` | 주제. `\|` 또는 `;`로 여러 개 (예: `일상\|직장`) |
| `notes` | 선택 메모 |

- UTF-8 (BOM 있어도 됨)
- 칸 안에 쉼표가 있으면 `"따옴표로 감싸기"` · 따옴표 자체는 `""`로 이스케이프
- 파싱 실패 시 앱에 빨간 안내가 뜹니다
- **CSV 지우기**를 누르면 업로드 덱이 localStorage에서 삭제됩니다

한국어 헤더 별칭도 일부 허용합니다 (`한국어`, `구어체`, `문어체`, `중남미`, `난이도`, `주제` 등).

## 카드 데이터 (개발자)

`cards.js`의 `window.FLASHCARDS`를 수정하고, `index.html`의 `EMBEDDED_CARDS`도 **같은 내용으로** 맞춰 주세요.

```js
{
  id: 55,
  topics: ["일상"],
  difficulty: "쉬움",
  meaningKo: "한국어 문장",
  colloquialSpain: "본토 구어체",
  formalSpain: "문어체/격식",
  colloquialLatAm: "중남미 구어체",
  notes: "선택"
}
```

## 파일 구성

| 파일 | 설명 |
|------|------|
| `index.html` | UI + 학습 로직 (+ 내장 카드 백업) |
| `cards.js` | 기본 문장 데이터 |
| `sample-cards.csv` | CSV 업로드 템플릿 (예제 2행) |
| `README.md` | 이 안내 |
