# 스페인어 플래시카드 (스페인 본토 우선)

스페인 본토에서 일·생활을 하는 **30대 여성** 페르소나로 쓴 중급 이상 학습 앱입니다.  
사무실·동료·예약·심부름·친구·연인·행정(cita previa, banco, Seguridad Social lite)·주말 약속 표현을 중심으로 했습니다.

- **앞면**: 한국어 문장/뜻
- **뒷면**: 스페인어 세 가지 변형
  - **구어체 (스페인 본토)** — vosotros, vale, currar, ordenador 등
  - **문어체** — 격식·문어에 가까운 표현
  - **중남미 구어체** — 비교 학습용

공개 페이지: https://blackupjacob.github.io/spanish-flashcards/

## 발음 듣기 (TTS)

브라우저 내장 **Web Speech API**(`speechSynthesis`)로 읽어 줍니다. 서버·API 키 없음.

- 카드를 뒤집으면 각 스페인어 블록에 🔊 버튼: 구어체(본토)·문어체 → **es-ES**, 중남미 구어체 → **es-MX** (없으면 es-US·es-419 등 다른 중남미 음성)
- 로케일별로 가장 좋은 음성을 자동 선택(Enhanced/Premium/Natural·Google·Siri 우선, 장난감 음성 제외). 없으면 가장 가까운 스페인어 음성으로 읽고 안내가 뜹니다.
  - iPhone·iPad: 설정 > 손쉬운 사용 > 읽기 및 말하기 > 음성 > 스페인어 에서 스페인/멕시코 음성(향상된 음성) 다운로드
- «발음 듣기» 패널: 읽기 속도 **보통 / 천천히**, **뒤집으면 자동 재생**(기본 끔 · 혼합 모드는 목표 레지스터, 기본은 본토 구어체). 설정은 `spanish-flashcards-tts-v1`에 저장 (기존 학습 기록 키는 그대로).
- 재생 중 버튼을 다시 누르면 정지, 다른 버튼을 누르면 이전 음성을 끊고 새로 읽습니다. 카드를 되돌리거나 다음 카드로 넘어가면 멈춥니다.

## 오늘의 세트 · 주간 복습

- **오늘 세트**: 필터된 덱에서 **로컬 날짜 시드**로 섞어 하루치 카드를 뽑습니다. 같은 날·같은 필터면 같은 순서, 다음 날이면 다른 구성입니다. UI에 오늘 날짜와 «오늘의 세트»가 표시됩니다.
- **하루 목표**: 기본 **18장** (12 / 15 / 18 / 20 / 25 선택 가능).
- **주간 복습**: 맞혀도 롤링 **7일** 안에 대략 **2번** 다시 나옵니다.
  - 첫 맞음 → 주 안에 한 번 더 복습 일정
  - 틀림 → 같은 세션 큐에 재삽입 + 주간 노출에도 포함
- 스케줄은 브라우저 `localStorage`에 카드 id별로 저장됩니다.


## 주간 레벨 보고 (DELE / CEFR 추정)

학습 기록(맞음·틀림, 난이도, 주제)을 `localStorage`에 쌓아 **달력 주(월–일)** 기준으로 추정 레벨을 보여 줍니다.

- UI: 접이식 패널 **«주간 레벨 보고»** (오늘의 세트 바로 아래)
- 표시: 추정 레벨(A1–C2), 근거(정답률·주로 푼 난이도), 학습 장수·정답률·난이도/주제 구성, 지난 주 추정(최대 8주)
- **보고서 복사** 버튼으로 한국어 요약을 클립보드에 복사
- **추정 · 학습 기록 기반**이며 공식 DELE 결과가 아닙니다. 실제 DELE는 공인 시험이 필요합니다.

### 레벨 추정 방식 (휴리스틱)

1. 난이도 대역 → 기본 점수: 아주쉬움≈A2–B1(1.5), 쉬움≈B1(2), 어려움≈B2(3), 아주어려움≈C1(4)
2. 이번 주 정답률로 가감: 어려운 카드 고정확 → 상향, 쉬운 카드 저정확 → 하향
3. 학습량이 적으면 높은 등급을 과신하지 않도록 보정

## 사용 방법

1. **주제**를 고릅니다. (일상, 직장, 여행, 음식, 감정, 문화, 시사·뉴스, 관용구, 격식 상황 — 여러 개 선택 가능)
2. **난이도**를 고릅니다. (`전체` / `아주쉬움` / `쉬움` / `어려움` / `아주어려움`)  
   ※ «아주쉬움»도 관광 기초가 아니라 **중급 초반** 수준입니다. 덱은 중급~상급에 치우쳐 있습니다.
3. **학습 모드**
   - **기본 학습**: 한국어 → 스페인어(본토 구어 기준). 뒷면에 세 변형 모두 표시.
   - **혼합 재학습**: 앞면은 여전히 한국어. 카드마다 **구어체 / 문어체 / 중남미** 중 하나를 목표로 지정합니다.
4. **내 CSV 덱** (선택): 직접 만든 문장 CSV를 올려 공부할 수 있습니다.
5. 카드를 **탭**해 뒤집으면 스페인어 답이 나옵니다. **맞음 / 틀림** 버튼은 뒤집힌 뒤에만 보입니다.
6. 답 화면에서 그 문장의 난이도를 바꿀 수 있습니다. 변경은 `localStorage`에 저장됩니다.

## CSV로 카드 추가

1. [sample-cards.csv](sample-cards.csv)를 받아 열을 맞춥니다. (Excel은 **UTF-8 CSV**로 저장)
2. 앱에서 파일을 선택합니다.
3. 덱 출처: **기본 덱** / **CSV만** / **합치기**

### 열 (헤더)

| 열 이름 | 설명 |
|---------|------|
| `front_ko` | 앞면 한국어 문장 (필수) |
| `colloquial_es` | 스페인 본토 구어체 (필수) |
| `formal_es` | 문어체/격식 (필수) |
| `latam_colloquial_es` | 중남미 구어체 (필수) |
| `difficulty` | `아주쉬움` \| `쉬움` \| `어려움` \| `아주어려움` |
| `topics` | 주제. `\|` 또는 `;`로 여러 개 (예: `일상\|직장`) |
| `notes` | 선택 메모 |
