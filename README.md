# 스페인어 플래시카드 (스페인 본토 우선)

아내를 위한 중급 이상 스페인어 학습 앱입니다.

- **앞면**: 한국어 문장/뜻
- **뒷면**: 스페인어 세 가지 변형
  - **구어체 (스페인 본토)** — vosotros, ordenador, vale 등 본토 표현 우선
  - **문어체** — 격식·문어에 가까운 표현
  - **중남미 구어체** — 비교 학습용

공개 페이지: https://blackupjacob.github.io/spanish-flashcards/

## 사용 방법

1. **주제**를 고릅니다. (일상, 직장, 여행, 음식, 감정, 문화, 시사·뉴스, 관용구, 격식 상황 — 여러 개 선택 가능)
2. **난이도**를 고릅니다. (`전체` / `아주쉬움` / `쉬움` / `어려움` / `아주어려움`)  
   ※ «아주쉬움»도 관광 기초가 아니라 **중급 초반** 수준입니다.
3. **학습 모드**
   - **기본 학습**: 한국어 → 스페인어(본토 구어 기준). 뒷면에 세 변형 모두 표시.
   - **혼합 재학습**: 앞면은 여전히 한국어. 카드마다 **구어체 / 문어체 / 중남미** 중 하나를 목표로 지정해, 그 레지스터로 말해 보게 합니다. 뒷면에서 목표가 강조됩니다. (한 바퀴 끝난 뒤 요약 화면에서 바로 시작할 수 있어요.)
4. 카드를 **탭**해 뒤집고 **맞음 / 틀림**을 고릅니다. 틀린 카드는 큐에 다시 들어갑니다.
5. 진행 상태는 브라우저 `localStorage`에 저장됩니다.

모바일·태블릿에 맞춰 한국어 UI로 만들었습니다.

## 카드 데이터

`cards.js`의 `window.FLASHCARDS`를 수정합니다. `index.html`의 `EMBEDDED_CARDS`도 **같은 내용으로** 맞춰 주세요. (`cards.js`가 막히는 환경 대비)

```js
{
  id: 55,
  topics: ["일상"],
  difficulty: "쉬움",           // 아주쉬움 | 쉬움 | 어려움 | 아주어려움
  meaningKo: "한국어 문장",
  colloquialSpain: "본토 구어체",
  formalSpain: "문어체/격식",
  colloquialLatAm: "중남미 구어체",
  notes: "선택 — 어휘 차이 메모"
}
```

주제 목록은 `window.TOPICS`에 있습니다.
