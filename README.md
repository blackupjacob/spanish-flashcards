# 스페인어 플래시카드

아내를 위한 일상 스페인어 문장 학습 앱입니다.  
앞면은 스페인어, 뒷면은 한국어 뜻입니다.

## 여는 방법

1. `index.html` 파일을 브라우저에서 엽니다.  
   - 파일을 더블클릭하거나  
   - 브라우저로 끌어다 놓아도 됩니다.
2. 인터넷 연결 없이 오프라인으로 사용할 수 있습니다.
3. 모바일·태블릿에서도 잘 보이도록 만들어 두었습니다.

> 참고: 일부 브라우저에서 `cards.js`가 막히면 `index.html` 안의 내장 카드 데이터가 대신 사용됩니다.  
> 카드를 수정했다면 **`cards.js`와 `index.html`의 `EMBEDDED_CARDS`를 함께** 맞춰 주세요. (보통은 `cards.js`만 수정해도 됩니다.)

로컬 서버로 열고 싶다면 (선택):

```bash
cd /workspace/spanish-flashcards
python3 -m http.server 8080
```

이후 브라우저에서 `http://localhost:8080` 으로 접속합니다.

## 사용 방법

1. 위쪽 **난이도 필터**를 고릅니다. (`전체` / `아주쉬움` / `쉬움` / `어려움` / `아주어려움`)
2. 카드를 **탭(클릭)** 하면 뒤집혀 한국어 뜻이 나옵니다.
3. **맞음** 또는 **틀림**을 누릅니다.
4. 틀린 카드는 잠시 뒤(또는 큐 끝에서) 다시 나와 복습합니다.
5. 큐가 비면 **세션 요약**이 표시됩니다.

진행 상태는 브라우저 `localStorage`에 저장되어, 같은 기기·브라우저에서 이어할 수 있습니다.

## 카드 추가·수정

`cards.js` 파일을 엽니다. `window.FLASHCARDS` 배열에 객체를 추가합니다.

```js
{
  id: 21,                          // 고유 번호 (다른 카드와 겹치지 않게)
  front: "Hasta luego.",           // 스페인어 (앞면)
  back: "나중에 봐.",               // 한국어 (뒷면)
  difficulty: "쉬움"               // 아주쉬움 | 쉬움 | 어려움 | 아주어려움
}
```

저장한 뒤 `index.html`을 새로고침하면 반영됩니다.  
(`cards.js`를 쓸 수 없는 환경이라면 `index.html` 안의 `EMBEDDED_CARDS`에도 같은 내용을 넣어 주세요.)

## 파일 구성

| 파일 | 설명 |
|------|------|
| `index.html` | 앱 전체 (디자인 + 학습 로직) |
| `cards.js` | 문장 데이터 (여기만 편집해도 됨) |
| `README.md` | 이 안내 문서 |

백엔드·빌드 도구는 필요 없습니다.
